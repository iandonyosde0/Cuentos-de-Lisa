Esta magia tiene dos vertientes:
1. Continúa: consiste en generar una barrera a la que se le alimenta de forma continua. Esta clase ofrece una mayor protección, pero es muy agotador para el usuario. 
2. Fija: el usuario crea una barrera con una cantidad x de maná, no hace falta alimentarla de forma continua, pero ofrece una protección menor.
